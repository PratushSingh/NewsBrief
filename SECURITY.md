# Security policy

## Supported version

Security updates target the current `main` branch.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's
private vulnerability reporting feature for the repository, including impact,
reproduction steps, and any proposed mitigation. Expect an acknowledgement
within seven days.

Never include real credentials, personal data, or third-party session cookies
in a report. The application is intentionally public and has no authentication
or user accounts.

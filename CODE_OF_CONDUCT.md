# Code of Conduct

We are committed to a welcoming, harassment-free project for everyone.
Contributors should communicate respectfully, accept constructive feedback,
focus on the work, and avoid personal attacks or discriminatory language.

Project maintainers may edit or remove comments, commits, issues, and other
contributions that violate these expectations. Serious or repeated violations
may result in a temporary or permanent ban from project spaces.

Report conduct concerns privately to the repository maintainers. Reports will
be reviewed fairly and with appropriate confidentiality.
